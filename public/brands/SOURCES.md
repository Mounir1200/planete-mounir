# Logos et couleurs des organisations

Sources vérifiées le 27 octobre 2026. Ces marques identifient les organisations du parcours de Mounir, sans implication de partenariat ni d'approbation du portfolio. Les logos appartiennent à leurs titulaires. Les fichiers ne sont ni redessinés ni recolorés.

Les valeurs ci-dessous sont celles publiées dans les styles web officiels, et non des références Pantone/CMJN inventées. Les matériaux naturels des bâtiments (pierre, métal, verre) gardent leur propre couleur.

## ESSCA

- Site et kit média officiels : https://www.essca.eu/a-propos/espace-presse-de-l-essca/kit-media/
- `essca.svg` : SVG du lien `.c-logo.c-header__logo` dans l'en-tête de cette page. Les tracés sont conservés tels quels ; `currentColor` est résolu en `#d60020`, la couleur déclarée par le site pour son logo. La source définit `viewBox="0 0 204 61"`.
- Styles source : https://www.essca.eu/app/themes/default/assets/stylesheets/front-b97bc36c7b.css
- Palette web utilisée : rouge `#d60020`, texte `#262626`, fond clair `#eeece2`.
- `essca-horizontal.png` : original du kit média conservé pour référence : https://www.essca.eu/app/uploads/2024/09/logo-essca-horizontal.png (1120 × 746 ; ses marges transparentes ne sont pas supprimées).
- Le nom de projet **l’ESSCABOT** reste distinct de l'organisation **ESSCA** dans les contenus du portfolio.

## ESAIP Engineering School

- Site officiel : https://www.esaip.org/
- Nouvelle identité annoncée le 18 septembre 2026 : https://www.esaip.org/actualite/une-nouvelle-identite-visuelle-pour-lesaip/
- `esaip-header.png` : fichier affiché dans l'en-tête officiel, représentant bien la nouvelle identité « ESAIP Engineering School » malgré le dossier daté 2024 : https://www.esaip.org/wp-content/uploads/2024/10/ESAIP-1024x372-1.png (1024 × 372, original conservé).
- `esaip-engineering-school.png` : planche officielle confirmant les versions horizontale et verticale : https://www.esaip.org/wp-content/uploads/2026/09/Nouveau-Logo-ESAIP-1024x354.png. Document de référence, non utilisé comme un logo composé dans l'interface.
- Couleurs dans les propriétés globales inline du site officiel : `--wp--preset--color--primary: #3878BD`, `--wp--preset--color--contrast: #242756`, `--wp--preset--color--base: #FFFFFF`.
- Palette utilisée : bleu ESAIP `#3878bd`, bleu foncé `#242756`, blanc `#ffffff`.
- Le site explique le rattachement au Groupe Excelia et le maintien du bleu ESAIP. Aucune modification des dates ou diplômes du parcours de Mounir n'en est déduite.

## Moov Africa Burkina Faso

- Site officiel de la filiale concernée par l'expérience professionnelle : https://moov-africa.bf/
- `moov-africa-burkina.png` : logo original de l'en-tête, également déclaré comme logo de l'organisation dans les données structurées du site : https://moov-africa.bf/wp-content/uploads/2026/01/cropped-logo-moov.png (325 × 150).
- Styles source : https://moov-africa.bf/wp-content/themes/moovafricabf_2026/assets/css/moovafrica.css
- Propriétés officielles : `--pbmit-global-color: #fa8100`, `--pbmit-secondary-color: #0059a1`, `--pbmit-light-color: #f6f6f6`.
- Palette utilisée : orange `#fa8100`, bleu `#0059a1`, fond clair `#f6f6f6`.
- Le texte d'expérience « Moov Africa Burkina » est conservé. Le logo générique de la marque est bien celui servi par le site burkinabè, sans emprunter de signature à une autre filiale.

## Intégration

- Configuration partagée : `src/content/brands.js`.
- Panneaux 3D : `src/world/landmarks/brandPlaque.js` affiche le fichier original sur une plaque blanche en conservant son ratio et ses couleurs, sans filtrage colorimétrique ou réinterprétation générative.
- Fiches HTML : bandeau logo lié au site officiel ; il ne remplace pas les titres du projet ou de l'expérience.
